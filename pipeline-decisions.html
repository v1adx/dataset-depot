Dry run

How a dry run differs from a real one

  • The verdict and the version rule are shared, so a dry run and a real run cannot drift apart. Sources are asked for their version and state is read from disk; nothing else runs and nothing is written.
  • Versions are projected forward through the graph: each node is judged against what its dependencies will become.
  • Extract does not run, so the projection misses three things: a version the extractor would set itself, an empty answer from the source, and data that matches the cache. A dry run may show more work than a real run does, never less.
